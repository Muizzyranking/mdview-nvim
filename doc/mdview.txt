==============================================================================
INTRODUCTION                                             *mdview* *mdview-intro*

mdview.nvim renders the current markdown buffer with cmark-gfm and shows the
result in a Chromium window started in `--app` mode: no tabs, no address bar,
no bookmarks. The window keeps its own profile, goes away on its own when you
stop the preview or close it, and the local server dies with Neovim — no
stale processes and no stray tabs in your normal browser session.

Features:

- Live sync: debounced re-renders while you type, and the page scrolls to
  follow your cursor (via `data-sourcepos`).
- Follows across buffers: switch buffers or files and the same window
  re-targets to the markdown file you open.
- Local images: relative image paths resolve against the file's directory
  (or a configurable root), served by the plugin's localhost server. Large
  files are rejected and path traversal is blocked.
- Link following: relative links to markdown files open the linked file in
  Neovim (the preview re-targets); `http(s)` links open in your normal
  browser.
- File tracking in the window title: the Chromium window title shows the
  previewed file's name.
- Dark and light: follows `vim.o.background` by default; flip a running
  preview with |:MdViewStyle| without restarting the window.
- Disposable: each session's browser profile and server are torn down when
  the window closes, the preview stops, or Neovim exits.
- Lean startup: the `plugin/` entry only defines the `:MdView*` commands.
  Nothing loads until a command or keymap fires.
- Hardened: sandboxed image responses, per-request host checks, and a strict
  default CSP for the preview document.

Requirements:

- Neovim 0.10 or newer.
- cmark-gfm <https://github.com/github/cmark-gfm> on your $PATH.
- A Chromium-based browser (Chrome, Chromium, Brave...). If it is missing,
  the preview falls back to your default browser.

==============================================================================
SETUP                                                     *mdview-setup*

Call |mdview.setup()| once, ideally from your plugin manager's config hook: >
	require("mdview").setup({})
<
mdview.setup({opts})                                     *mdview.setup()*
	Merge {opts} into the defaults (see |mdview-config|), then map the
	buffer-local keymap for every markdown buffer: loaded ones now, and
	matching filetypes as they appear. See |mdview-config-keymap|.
	When reused, the old keymap group is cleared first, so calling setup()
	twice with different keymaps is safe (the buffers already mapped keep
	their old mapping until re-sourced; consider restarting).

==============================================================================
CONFIGURATION                                            *mdview-config*

Defaults are below. Pass overrides to |mdview.setup()|. >
	require("mdview").setup({
		keymap = "<leader>mp",           -- buffer-local keymap; false disables it
		filetypes = { "markdown" },      -- filetypes that get the keymap
		render_debounce = 250,           -- ms of pause before re-rendering
		-- image_root = function(buf)    -- where relative image paths resolve
		-- 	return vim.fs.root(buf, ".git") -- nil = the file's directory
		-- end,
		max_image_bytes = 20 * 1024 * 1024, -- refuse larger local assets
		theme = nil,                     -- "dark"/"light"; nil follows &background
		-- theme = "dark",
		-- browser = "google-chrome-stable", -- any chromium binary name
		-- csp = false,                  -- drop the Content-Security-Policy header
	})
<
mdview-config-enabled                                   *mdview-config-enabled*
	Type: `boolean|fun(): boolean`   Default: `true`
	Set to `false` (or a function returning false) to keep commands usable
	while the keymap stops toggling previews.

mdview-config-browser                                   *mdview-config-browser*
	Type: `string`   Default: `"google-chrome-stable"`
	Binary used to open the preview window, in `--app` mode. Must be
	Chromium-based. If the binary is missing on $PATH, the preview falls
	back to `vim.ui.open()` (your default browser) and the window title or
	close detection degrade accordingly.

mdview-config-filetypes                               *mdview-config-filetypes*
	Type: `string[]`   Default: `{ "markdown", "markdown.pandoc", "markdown.mdx" }`
	Filetypes that receive the buffer-local toggle keymap.

mdview-config-keymap                                     *mdview-config-keymap*
	Type: `string|false`   Default: `"<leader>mp"`
	Buffer-local normal-mode mapping that toggles the preview for that
	buffer. Set to `false` to skip mapping entirely.

mdview-config-render_debounce                     *mdview-config-render_debounce*
	Type: `integer`   Default: `250`
	Milliseconds of typing pause before a re-render is sent to the page.

mdview-config-image_root                               *mdview-config-image_root*
	Type: `string|fun(buf: integer): string|nil|nil`
	Default: `nil`
	Where relative image paths resolve from. `nil` means the markdown
	file's directory. A string is used as-is; a function receives the
	buffer number and may return a root (a common choice is the git root,
	so `../assets/x.png` works from nested files), or `nil` to fall back
	to the file's directory.

mdview-config-max_image_bytes                     *mdview-config-max_image_bytes*
	Type: `integer`   Default: `20 * 1024 * 1024`
	Largest local image the preview server will serve, in bytes. Larger
	files are reported in the page instead of loaded.

mdview-config-theme                                       *mdview-config-theme*
	Type: `"dark"|"light"|nil`   Default: `nil`
	Fix the style to `"dark"` or `"light"`. `nil` follows `vim.o.background`
	(and counts "auto" as dark). Changed live by |:MdViewStyle|, which also
	remembers the choice for the running session.

mdview-config-csp                                           *mdview-config-csp*
	Type: `string|false`   Default: see below >
		"default-src 'self'; script-src 'self'; style-src 'self'
		'unsafe-inline'; img-src 'self' https: data:; media-src 'self'
		https: data:; frame-src 'none'; object-src 'none';
		form-action 'none'; base-uri 'none'"
<
	Content-Security-Policy header for the preview page. The default keeps
	the page's own resources working and lets remote images load (README
	badges and the like), but stops the rendered markdown from running
	scripts, framing pages, submitting forms, or phoning home. Set to
	`false` to drop the header entirely.

==============================================================================
COMMANDS                                                  *mdview-commands*

:MdViewStart                                              *:MdViewStart*
	Start the preview for the current markdown buffer. Unsaved buffers
	report an error first: save before previewing.

:MdViewStop                                                *:MdViewStop*
	Stop the preview and close the window, tearing down the session's
	browser profile and server.

:MdViewToggle                                            *:MdViewToggle*
	Start the preview if it is not running for the current buffer, stop
	the previewed buffer otherwise.

:MdViewStyle {dark|light}                             *:MdViewStyle*
	Switch a running preview's look between dark and light without
	restarting the window, and remember the choice for that session.
												*:MdView-style-argument*
	{dark|light} is required; completions are "dark" and "light".

==============================================================================
API                                                          *mdview-api*

Functions are exposed on the `mdview` module and safe to call as
`require("mdview").<fn>()`.

mdview.setup({opts})                                     *mdview.setup()*
	See |mdview.setup()| above.

mdview.start()                                           *mdview.start()*
	Start the preview for the current buffer. Same as |:MdViewStart|.

mdview.stop()                                             *mdview.stop()*
	Stop the preview. Same as |:MdViewStop|.

mdview.toggle()                                         *mdview.toggle()*
	Start if not running for the current buffer, stop otherwise. Same as
	|:MdViewToggle|.

mdview.is_active([{buf}])                             *mdview.is_active()*
	Return `true` when the preview is running. With {buf}, reports
	whether that buffer is the previewed one.

mdview.status()                                           *mdview.status()*
	Return `nil` when nothing is previewed, or a table like: >
		{ buf = 4, port = 39211, url = "http://127.0.0.1:39211" }
<
	`buf` is the previewed buffer, `port` the listening localhost port,
	and `url` the page the browser window shows.

mdview.style({theme})                                    *mdview.style()*
	{theme} is `"dark"` or `"light"`. Same as |:MdViewStyle|.

==============================================================================
NOTES                                                      *mdview-notes*

- Unsaved buffers refuse to start a preview: save first.
- The default |mdview-config-csp| deliberately makes remote markdown
  *scripts* dead; images from `https:` and `data:` still load.
- Clicking an image or a link with no resolvable target is reported in a
  notification instead of silently ignored.
- Help pages are registered automatically by most plugin managers. To do
  it by hand: >
	:helptags ALL
<
